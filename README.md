# Madan Bhandari QA Workshop

A collection of materials, assignments, and practical exercises from the **QA Automation Workshop at Madan Bhandari Memorial College**.

## Contents

* **Assignments** — QA and software testing assignments
* **JMeter-Files** — Performance testing and JMeter resources
* **Selenium Demo 1** — Selenium automation examples
* **Syllabus and Cheat Sheets** — QA concepts, notes, and quick references
* **Test-API** — API testing examples and related files

## Tools

* Selenium
* Apache JMeter
* API Testing
* Java
